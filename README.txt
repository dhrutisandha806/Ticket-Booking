WAYFARE — OCEAN NEON (REALISTIC EDITION)

RUN
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open it in Chrome or Edge.
4. For testing Web Workers, open the folder in VS Code and use Live Server.

DESIGN
- Professional deep ocean-blue gradients with subtle cyan highlights
- Readable glass-style booking cards and warm gold action buttons
- QR graphic removed from the ticket confirmation
- Existing simulated booking and multithreading demonstration retained

NOTE
This is a demonstration website. Routes, availability, booking IDs and payment status are simulated; it does not issue real tickets or process real payments.
